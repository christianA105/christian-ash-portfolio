# Christian Ash Portfolio

A responsive personal portfolio showcasing my software development, front-end, UI/UX, and digital design work.

[![View Live Demo](https://img.shields.io/badge/View_Live_Demo-00F5C4?style=for-the-badge\&logo=githubpages\&logoColor=black)](https://christiana105.github.io/christian-ash-portfolio/)

## About the Project

This portfolio was designed and developed to introduce who I am, present my technical and creative skills, and showcase the projects I am building as I return to the technology field.

## Features

* Responsive design for desktop and mobile
* Accessible navigation
* Interactive project library
* CA DualDeck project interface
* Project screenshots and descriptions
* Live-demo and GitHub project links
* Contact and résumé options
* Custom cyan and teal visual design

## Built With

* HTML5
* CSS3
* JavaScript
* Git and GitHub
* Visual Studio Code
